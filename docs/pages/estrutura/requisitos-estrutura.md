# Requisitos de Estruturas
| Código | Descrição |
|---------|------------|
| **RF-LAB-01** | O Labirinto deve ter paredes de 1,2 cm de espessura e 5 cm de altura. |
| **RF-LAB-02** | O Labirinto deve ter tamanho 4x4 células. |
| **RF-LAB-03** | As paredes devem ser brancas no topo e vermelhas/pretas nas laterais. O chão deve ser preto fosco para evitar reflexos indesejados nos sensores ópticos. |
| **RF-ESTR-01** | A estrutura deve garantir que o robô suporte o próprio peso e consiga se mover. |
| **RF-ESTR-02** | O chassi deve suportar a montagem de sensores de forma que não haja interferência estrutural na leitura das paredes do labirinto. |
| **RF-ESTR-03** | A estrutura deve garantir que as rodas mantenham contato constante ao solo. |
| **RF-ESTR-04** | O robô deve estar contido em um quadrado de 16 cm × 16 cm. |
| **RNF-ESTR-01** | O material deve ser de baixo custo, resistente e de fácil fabricação. |
