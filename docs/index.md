# Início
Este ambiente reúne a documentação oficial do projeto desenvolvido na disciplina **Projeto Integrador de Engenharia I** da Universidade de Brasília (UnB).

Aqui estão organizadas as informações do projeto, as equipes envolvidas, o planejamento e as entregas realizadas ao longo do semestre.

O objetivo é centralizar o desenvolvimento do trabalho de forma clara, estruturada e acessível.

# Sobre o Projeto       
O **MicroMouse** é um projeto de robótica autônoma. O desafio consiste em construir um robô capaz de **percorrer de forma autônoma três labirintos**, utilizando estratégias de navegação e tomada de decisão para encontrar o melhor caminho até o objetivo.

O desenvolvimento do projeto envolve a construção completa do robô, incluindo **estrutura física, eletrônica, sistema de energia, sensores, hardware embarcado e lógica de busca e navegação**. Além do robô, será desenvolvida uma **interface web**, para acompanhamento dos **dados de telemetria em tempo real**, permitindo monitorar informações importantes sobre o desempenho do sistema durante a execução.

O projeto reúne conhecimentos de **engenharia de software, eletrônica, programação, sistemas embarcados e automação**, proporcionando uma experiência prática no desenvolvimento de sistemas inteligentes e autônomos.
